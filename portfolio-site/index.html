Architecture

WorkLens.Core contains domain entities, DTOs, enums, and abstractions without ASP.NET Core or Entity Framework dependencies.

WorkLens.Infrastructure implements EF Core persistence, repositories, migrations, feed providers, background services, resume matching, and Microsoft Graph integration.

WorkLens.Api is the composition root for HTTP routing, Problem Details, CORS, OpenAPI policy, and dependency registration.

The Angular client is feature-oriented and enters through a same-origin nginx gateway. In the normal Docker Compose topology, the API and SQL Server are private to the Compose network.

Capabilities

Job ingestion

RemoteOK, Remotive, Greenhouse, Dice MCP, Jobicy, We Work Remotely, and optional watch-feed ingestion with normalized persistence.

Application tracking

Status pipeline, history, notes, contacts, follow-up reminders, analytics, and configurable search profiles.

Resume matching

Optional OpenAI-assisted scoring behind an interface boundary with cached user-triggered results.

Communications

Optional Microsoft identity platform and Graph integration for associating Outlook messages with tracked applications.

Browser capture

Manifest V3 extension for explicit user-assisted capture of LinkedIn and Indeed job pages instead of brittle background scraping.

Operations

Docker Compose, EF migrations, health-aware startup, security headers, production-safe defaults, and GitHub Actions validation.

Engineering decisions

Feed providers perform network-bound work concurrently while persistence stays scoped and serialized around EF Core. Manual and hosted refresh cycles are prevented from overlapping.

Provider failures are isolated so one unavailable source does not stop healthy sources. Listing upserts use batched lookups rather than one existence query per listing.

Production configuration avoids raw exception leakage, disables OpenAPI by default, and does not implicitly migrate the database outside the explicit single-instance self-hosted profile.

CI validates Release builds, formatting, unit tests, migrations against a real SQL Server service, Angular production build/tests, critical dependency audit, extension syntax, Docker images, and this static overview.
